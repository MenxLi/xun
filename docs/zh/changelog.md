# 更新日志

## 1.5.0dev

### 核心

- 新增执行追踪（tracing）：取消链与 span 自动继承传播，流事件按 span 归因，子智能体派发携带 span 快照。
- 钩子参数 `AfterExecutionStepArgs` 新增可变的 `should_continue`，供扩展影响执行循环走向。
- `agent_wait` 返回结果时附带任务快照。
- 智能体终结时取消整个子智能体链。

### 工具与安全

- 移除 bash 工具的 `cd` 参数，改用命令内 `cd` 前缀；shell 操作符扫描改为默认拒绝：白名单外的纯符号 token 一律视为可疑。
- bash 启动前先检查进程池是否已关闭。
- 工具与命令重复注册改为幂等；命令覆盖需显式声明，不再静默替换。

### API 变更

- `openai_client` 改为可注入的懒加载属性。
- 钩子可按注册时返回的签名移除。
- 扩展 API 版本区间 `api_max_version` 改为半开区间 `[min, max)`。
- 显示层 `bind` 类型收窄为存活期智能体 `Agent[T.Alive]`。
- 新增 `CustomEvent` 显示事件：扩展自定义 JSON 负载，内置显示忽略，为自定义渲染预留。

### Web 服务与前端

- 新增 steering：智能体运行中可发送后续指令，在下一步执行前注入；待发送指令以卡片展示，可编辑 / 删除。
- 追踪视图：新增 trace 图与火焰图，火焰图支持尾部窗口缩放并过滤窗口内无耗时的行。
- 活跃智能体发出结论消息时自动刷新文件列表；修复表格列被不换行代码片段挤压的问题。

### 文档

- README 补充 Docker 前置条件；新增文档同步脚本。

## 1.4.3

- API 调用并发改为按智能体绑定的槽位分配：同一智能体优先复用此前的并发槽位，提升服务端前缀缓存命中。
- 文件与浏览器工具安全加固：浏览器拒绝 `file://` 等非法来源的 URL；`move` 对目标端同样确认。
- 压缩改进：用户消息新增 `is_synthetic` 标记，压缩时区别对待并提示省略间隙；摘要保留量默认由 16 提高到 24。
- 命令解析不再把 `#` 之后当作注释。
- 修复子智能体嵌套深度未按实际代数计数的问题。
- 修复执行中途取消时一次性钩子回调丢失的问题。
- 修复会话转储 / 压缩的若干问题：UTF-8 编码、递归压缩的 token 估算、空会话保护。
- 显示层事件存储改为可插拔后端：`EventStore` 协议，可通过 `display.event_store` 属性替换。
- 每次模型调用重试都会发出新的工作事件，前端不再停留在过期状态。
- Skills 扩展：脚本运行结果补充执行时长。
- 内部默认参数统一由环境变量配置（`_XUN_MAX_API_CALL_CONCURRENCY`）。

## 1.4.2

- 结构化输出解析失败改为重试，不再直接抛出。
- 默认 API 调用并发由 3 调整为 8。
- 模型消息事件新增 `conclusive` 标记，区分中间消息与结论消息。
- 精简框架的显示通知，执行错误尽量统一在入口层报告，不再重复输出。
- 工具调用失败不再额外发出提示：工具结果事件新增 `is_error` 标记；每个工具调用（含参数解析失败）都有成对事件记录。
- 显示方法 `info` / `warning` / `error` 更名 `display_info` / `display_warning` / `display_error`，旧名保留为别名。
- Web：标签页标题显示智能体运行 / 等待状态；设置菜单新增源码链接；失败的工具调用以图标标记，并在分组与会话头部汇总失败数。
- Web：未选中智能体的长模型消息现在可折叠为预览，提供展开 / 收起控制。

## 1.4.1

- 修复子智能体取消信号的传播：信号跨运行存活，修复大量子智能体场景下父智能体停止失败。
- API 并发许可的等待改为可取消，许可耗尽时取消请求不再被阻塞。
- 压缩的工具调用记录设上限，限制内存与存储增长。
- 子智能体嵌套深度可配置，默认由 3 调整为 2。
- Web：设置面板新增遮罩、菜单按钮与文档入口；预览缩放、文件搜索、记住上次会话。
- 文档：使用VitePress 构建。

## 1.4.0

### 核心与工具

- bash 工具集重设计：新增后台命令工具集，智能体可启动、等待、终止与查看长时间运行的命令，输出分离为日志文件，结果附执行时长。
- 命令风险评估重设计：按命令行结构逐项判定，危险模式直接拒绝而不进入确认；确认时可选填拒绝理由并回传给智能体，评估结论附简要原因。
- 收紧默认命令允许列表：移除 `curl` / `wget` / `sed` 等风险命令，改走风险评估与确认。
- `apply_patch` 基于 `git apply` 重写：跨平台行为一致、报错信息更清晰（需要安装 Git）。
- 子智能体支持后台执行：`agent_run_parallel` 替换为 agent 异步接口，可并行派发多个子智能体并按需收取结果。
- 取消错误携带取消原因。

### 扩展系统

- 新增 `xune` 命令：扩展可声明专属 CLI（`cli=(parser, handler)`），通过 `xune <name> ...` 直接运行。
- 扩展可声明 `data_version`，框架提供布局统一、按版本隔离的数据目录（`ExtensionContext.data_dir`）。
- 新增 `completion_token_update` 钩子：推送每次模型调用的 token 用量（含缓存命中数）。
- 新增 `stat` 扩展：记录 token 与工具调用用量，注册在会话中展示报表，可通过 `xune stat` 管理报表与按日/周/月的用户预算。
- 内置扩展声明所依赖的最低核心 API 版本：MCP ≥ 1.3.0，Skills / stat ≥ 1.4.0。

### API 变更

- `Agent.state` 升级为类型化容器 `AgentState`：区分持久 / 运行时条目，获取改用 `get_entry(key, factory)`。
- 生命周期类型标注移入 `agent_lifecycle.py`。
- `cancellable_execution()` 更名 `run_scope()`。
- `set_persistent_section` 更名 `set_system_persistent_section`。
- `to_json` / `from_json` 改以结构化 JSON 为接口；新增 `ToJson` / `FromJson` 协议导出。
- 事件缓冲默认容量改为 0（由消费方设置），设置方法改为链式的 `with_buffer_size()`。
- 子智能体工具集重新设计：`agent_run_parallel` 替换为 agent 异步接口。

### CLI 与容器

- 交互式 CLI 显示样式优化；文件相关命令在所有交互式入口统一注册。
- 修复 `xunc` 向容器转发参数的问题。
- 新增 `xunx shell <user>`：进入用户容器 shell，可用 `--exec` / `--cwd` 指定程序与工作目录。

### Web 服务与前端

- 智能体加入 / 离开事件仅在末尾批次显示预览；自动确认标记并入活动批次展示。

## 1.3.0

### 扩展系统

- 新增 MCP 扩展：作为 MCP 客户端连接服务器（支持 stdio），将其工具暴露为 xun 工具。
- 新增 Skills 扩展：支持 Agent Skills 技能包，自动发现并注入精简目录，按需激活，目录与工具自动同步。
- 新增扩展配置项 `extension_settings`：按扩展名分桶，扩展通过 `ExtensionContext.settings` 读取。
- 工具箱支持禁用状态查询、`pop` 移除与注册原生函数，支撑 MCP 等扩展。

### 核心与工具

- 会话消息重构为类型化消息类，系统提示、用户消息、原始消息各司其职。
- 结构化输出改为软约束：注册工具时不再强制 `response_format`，避免跳过工具调用。
- 完成请求的重试与退避增强；用户新指令可重新获得退避窗口。
- 风险评估子智能体限制迭代与工具调用预算（最多 3 次工具调用）。
- 新增 `sleep` 工具；`browser` 的 `evaluate` 支持超时。
- 新增 `/handoff` 命令：将当前任务打包为 zip 交接包。
- `/config` 支持编辑配置，`/revise` 接受新内容，`/compact` 解析优化，`/render` 路径校验与后缀宽容。
- 写文件的内置命令从默认命令中分离，仅在交互式入口注册。

### CLI

- 命令行改用 prompt_toolkit：历史搜索、`/` 斜杠命令与 `@文件` 引用补全；确认提示可中断当前输入并原样恢复。
- 修复多线程下的显示错乱。

### 配置与提示词

- `AGENTS.md` 作为系统提示词独立段落加载，新增 `load_project_instructions` 开关。

### Web 服务与前端

- HTML / Markdown 预览：相对路径图片、多文件 HTML、可渲染文件默认预览。
- 预览支持文本文件的编辑与新建；支持创建嵌套目录。
- 设置菜单显示构建版本与 commit。
- 显示层重构：事件存储独立、事件与显示隔离；中屏控制样式、表格列宽、提示卡片与光谱动画等细节优化。

### 容器与多用户

- 用户容器启动时传入用户名环境变量。

- 斜杠命令缓存随会话更新。

## 1.1.0

### 扩展系统（新增）

- `$XUN_HOME/extensions/` 下的源文件在每个智能体初始化时自动加载，支持包形式 `{name}/setup_extension.py` 与扁平形式 `{name}.py`；入口 `setup_extension(ctx)` 。
- 导入或初始化失败只告警，不阻断启动；配置项 `enable_extensions` 可关闭。
- 新增显示层钩子 `before_display_info` / `before_display_warning` / `before_display_error`，可拦截智能体输出；新增 `/extensions` 命令与仓库内示例。

### 核心与工具

- 会话压缩分级：先回收旧工具结果，仍超标才转摘要压缩，摘要后仍超标可继续再压；摘要正文不再混入 info 消息。
- 取消事件改为链式结构，父智能体取消级联到子智能体；Web 端等待输入时同样响应取消。
- 生命周期状态独立为 `agent_state.py`；显示方法抽为 `AgentDisplayMixin` 并纳入类型状态约束。
- 子智能体 getter 参数改为 dataclass `AgentGetterParam`。
- `shell` 工具更名为 `bash`；`copy` 覆盖已存在目标需要确认。
- `get_choice` / `get_confirm` 返回 `ChoiceOutcome`（选择值 + 来源）；自动确认不再写入命令与路径允许列表。
- 修复工具调用参数被 JSON 修复后与历史不同步的问题。

### 配置与提示词

- `auto_confirm` 支持环境变量 `XUN_AUTO_CONFIRM`。
- 系统提示词要求先查看并遵循工作目录下的 `AGENTS.md`。

### Web 服务与前端

- 文件浏览：PDF 与全屏预览、文本预览语法高亮、行内编辑；列表与信息分列，扫描更快；窄屏下面板互斥。
- 上传支持整个目录，结果通知列出全部文件并自动消失。
- 新增静态目录托管 `/srv/`，可直接访问工作目录里的站点（默认 1 小时过期）。
- 事件列表加载与传输优化；输入内容跨会话保持；界面文案中/英双语。

### 容器与多用户

- 容器启动时把宿主 xun home 复制进 `/.xun`（只取 `config.json` 与 `extensions`）。
- `xunc --env` / `xunx serve --env` 支持 `NAME=VALUE` 赋值与通配转发宿主变量。
- `xunx` 容器持久化：`serve` 重启后重新接管已有容器并保留会话，已删除用户的容器在对账时清理。
- 新增 `xunx upgrade`，由运行中的 `serve` 在下一次对账时重建容器。

### 文档

- 新增中英双语文档（MkDocs），Web 服务在 `/docs` 提供无需登录的访问。
